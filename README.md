# Сервис переводов с карты на карту

## Описание
Сервис предоставляет REST API для осуществления денежных переводов между банковскими картами.

## Функциональность
- Перевод денег с карты на карту
- Двухэтапная система подтверждения перевода (подготовка и подтверждение)
- Проверка данных карты и баланса

## Архитектура
Приложение построено на Spring Boot и использует следующие компоненты:
- Controller: обработка HTTP-запросов
- Service: бизнес-логика
- Repository: хранение данных о картах
- Model: объекты данных
- Exception: обработка ошибок

## Пользователи по умолчанию
В системе предустановлены следующие карты:
- Карта 1111111111111111, CVV 111, баланс 10000 руб.
- Карта 2222222222222222, CVV 222, баланс 10000 руб.

## API
### Перевод денег
POST /transfer 
{
    "cardFromNumber": "1111111111111111",
    "cardFromValidTill": "12/24",
    "cardFromCVV": "111",
    "cardToNumber": "2222222222222222",
    "amount": {
    "value": 100,
    "currency": "RUR"
    }
}
### Подтверждение перевода
POST /confirmOperation

{
    "operationId": "операционный идентификатор, полученный при переводе",
    "code": "0000"
}

## Запуск приложения
1. Клонировать репозиторий
2. Выполнить команду: `./mvnw spring-boot:run`
3. Сервис будет доступен по адресу: http://localhost:8080
